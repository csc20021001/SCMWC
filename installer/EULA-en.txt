1. WHAT THIS SOFTWARE DOES

SCMWC repeatedly captures the window region you select, analyses the
pixels in that region, and raises a notification when the condition you chose
is met.

Capture is performed by asking the target application to render itself through
the Windows PrintWindow interface. Only windows you explicitly select are
captured. The whole desktop is not captured, and keyboard input is not recorded.

4. DETECTION IS INFERENCE AND CAN BE WRONG

The software reasons about pixels. It does not read the internal state of the
program you are watching.

Specifically regarding "tell me when it finishes": Windows progress bar controls
animate while filling, so a program that resets its progress immediately upon
completion may never render a fully filled bar at all. In that case SCMWC
infers completion from a large backwards jump in progress. That is an inference,
not an observation. It may report a failed retry as a completed job, and in some
layouts it may not detect completion at all.

Colour-change and general change detection can likewise be thrown off by screen
layout, display scaling, colour management or graphics driver behaviour.


5. THIS SOFTWARE MOVES YOUR WINDOWS

When a window you are watching is minimised, SCMWC restores it and moves
it outside the visible desktop area so that it continues to render and can still
be captured. This is deliberate: a minimised window draws nothing and cannot be
captured at all.

You can return such windows at any time using "put background windows back" in
the tray menu. They are also restored automatically when the software exits.

If your workflow cannot tolerate windows being moved, do not use this software.


6. PHONE ALERTS AND DATA LEAVING YOUR MACHINE

Discord alerts are disabled by default and only become active after you supply a

Once enabled, the following is transmitted over the internet to Discord, a third

"Attach a screenshot" is off by default. Enabling it means uploading the contents
