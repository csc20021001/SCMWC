不管那塊畫面屬於哪個程式 —— Citrix、SAP、公司 2005 年寫的內部系統、 瀏覽器後台、算圖進度 —— 它只看畫素，不需要跟任何程式整合。

Watch any region of your screen and get notified when it changes. Works with any application, because it only looks at pixels.

它能做什麼

四種通知條件

畫面有變化就通知、進度條跑完才通知、跑到指定 % 通知、顏色變了通知。 後三種是邊緣觸發，跑完只響一次，不會一直吵。

自己找出進度條

直接框整個視窗就好，程式會在範圍內找出那條進度條。 就算它跑滿之後立刻歸零重跑，也抓得到。

推播到手機

接上 Discord webhook，電腦在跑東西時人可以先去吃飯， 跑完手機會響。

最小化也繼續看

最小化的視窗不會繪製，所以程式會把它移到背景繼續監視， 而不是叫你別按最小化。

不會靜默失效

抓不到畫面時會明講原因，那段時間也會從「看得到的時間」扣掉。 通知紀錄讓你分辨是條件沒成立，還是 Windows 擋掉了通知。

很輕

單一執行檔，不到 100 KB，沒有背景服務、沒有安裝時的相依套件。

下載時 Windows 會跳警告，這是正常的

這個版本還沒有購買程式碼簽章憑證，所以 Microsoft Defender SmartScreen 會顯示「Windows 已保護您的電腦」。這代表「這個檔案還沒有累積足夠的下載信譽」， 不代表它被判定為惡意程式。

  1. 點「其他資訊」
  2. 再點「仍要執行」

不放心的話，可以先把安裝檔上傳到 VirusTotal 用七十幾種防毒引擎掃描再決定。 簽章憑證會在之後補上。

你應該知道的事

它會移動你的視窗 被監視的視窗一旦最小化，程式會把它還原並移到螢幕可見範圍之外， 以便繼續擷取畫面。可以隨時從系統匣選單放回來，關閉程式時也會自動還原。
「跑完了」是推論 Windows 的進度條填滿時帶有動畫，若程式完成後立即重設， 畫面上可能從未出現完整填滿的狀態。這時會依「進度大幅倒退」推論已完成， 可能把失敗重試誤判為跑完。
不要用在關鍵用途 這是便利工具，不是監控或警報系統。醫療、工安、消防、交通、 自動交易等「沒收到通知就可能出事」的場景請不要使用。
手機推播會把資料送到 Discord 啟用後，視窗標題與觸發原因會傳到你指定的 Discord 頻道。 附上截圖的選項預設關閉。在公司環境使用前請自行確認合規。
有些畫面抓不到 全螢幕遊戲、有版權保護的影片視窗不允許其他程式讀取畫面。 這種情況清單上會顯示「看不到畫面」並說明原因。

完整條款請見安裝時顯示的 使用條款與免責聲明。

系統需求

作業系統Windows 10 1607 以上 / Windows 11
相依套件.NET Framework 4.x（Windows 內建，不需另外安裝）
安裝位置%LOCALAPPDATA%\Programs\ScreenWatch，不需要管理員權限
設定檔%LOCALAPPDATA%\ScreenWatch\config.txt，解除安裝時一併刪除
資料蒐集沒有。不含分析、不含廣告，除了你自己設定的 Discord 推播之外不對外連線。
